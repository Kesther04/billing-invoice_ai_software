# TraqBill — AI Revenue Assistant

TraqBill is an AI revenue assistant built for freelancers and agencies who invoice 
clients and need to get paid — reliably, on time, and without manual work.

It owns one problem completely: the gap between sending an invoice and receiving 
payment. TraqBill closes that gap automatically.

## What It Does

- **Smart Invoicing** — Generate invoices through simple prompts or manually, 
  with all client and payment details structured and stored cleanly
- **Automated Follow-ups** — Rule-based payment reminder sequences that go out 
  automatically without manual effort
- **Late-Payment Risk Detection** — Flags clients likely to pay late before they do, 
  based on payment behavior patterns
- **Cash Flow Visibility** — Forward-looking dashboard showing total revenue, 
  collected this month, pending, and overdue at a glance
- **AI Prompt History** — Tracks all AI-generated invoice interactions for 
  reference and audit

## Tech Stack

### Client
- React + TypeScript
- Tailwind CSS
- Vite

### Server
- Express.js + TypeScript
- PostgreSQL
- Prisma ORM
- Groq API (AI invoice generation)
